# genie-web

English | [简体中文](./README.zh-CN.md)

Visual inspiration and the mesh-warp algorithm are based on Chad Etzel’s [MeshWarpEffect](https://github.com/jazzychad/MeshWarpEffect) — a macOS Genie Effect recreated with a deformable mesh. `genie-web` brings that technique to the modern web using WebGL. Special thanks to the original author for sharing it.

```bash
npm i genie-web
# bun add genie-web
```

A unified configuration schema shared seamlessly across Vanilla JavaScript, React, Vue, and Svelte.

> [!NOTE]
> Note: This port was generated by an LLM.

## Required vs. Optional Options

**Vanilla (`createGenie`) — Required**

| Field | Type | Description |
| --- | --- | --- |
| `target` | `string \| HTMLElement` | The target element to animate. Accepts a CSS selector or a DOM node. |
| `origin` | See below | The anchor point where the element shrinks into or expands from. |

**Framework Components — Required**

| Field | Type | Description |
| --- | --- | --- |
| `open` | `boolean` | Visibility state. `true` expands the element (warp in), `false` minimizes it to the anchor (warp out). |
| `origin` | See below | The anchor point (same as Vanilla). The component animates its root/child container. |

All other options are optional. Default values are listed in the table below.

`origin` accepts:

- A CSS selector string (`"#dock-icon"`)
- An `Element` node
- A `DOMRect` instance
- Viewport pixel coordinates `{ left, top, width, height }`

## Configuration

Pass these in `createGenie({ … })`, update them via `genie.set({ … })`, or provide them via the `config` prop on React / Vue / Svelte components. The Svelte action also accepts these properties alongside `open` and `origin` in a flat object.

| Name | Required | Default | Type | Description |
| --- | --- | --- | --- | --- |
| `duration` | No | `680` | `number` | Animation duration in milliseconds. |
| `direction` | No | `"auto"` | `"auto" \| "top" \| "right" \| "bottom" \| "left"` | The edge of `target` where the funnel connects. `"auto"` dynamically chooses the edge based on the relative position of `origin` to the target; or explicitly lock to `"top"`, `"right"`, `"bottom"`, or `"left"`. |
| `slideEnd` | No | `0.5` | `number` (`0–1`) | Progress point at which near-edge shearing completes. Smaller values pinch the mouth of the funnel earlier. |
| `translateStart` | No | `0.38` | `number` (`0–1`) | Progress point at which the entire mesh starts translating toward `origin`. Overlaps with the shearing phase. |
| `easing` | No | `"linear"` | `"linear" \| "easeOut" \| "easeInOut"` | Easing function for the **overall animation timeline** (progress 0 → 1). |
| `curve` | No | `"inOut"` | `"inOut" \| "in" \| "out" \| "linear"` | Easing curve for the **funnel side walls**, defining the curvature during collapse/expansion. |
| `columns` | No | `20` | `number` | Number of horizontal mesh subdivisions. Higher values yield smoother curves at the cost of rendering performance. |
| `rows` | No | `48` | `number` | Number of vertical mesh subdivisions. |
| `fadeStart` | No | `0.88` | `number` (`0–1`) | Progress point at which the mesh begins fading out (primarily during hide animations). |
| `zIndex` | No | `2147483000` | `number` | CSS `z-index` for the overlay WebGL canvas. |
| `wireframe` | No | `false` | `boolean` | Render the WebGL mesh in wireframe mode for debugging and inspecting warp geometry. |
| `reducedMotion` | No | `"auto"` | `boolean \| "auto"` | Accessibility motion preference. `"auto"` respects the system `prefers-reduced-motion` setting; `true` disables warp animation and toggles visibility immediately; `false` always plays the animation. |
| `capture` | No | Built-in snapshot | `(el) => Promise<canvas \| image>` | Custom DOM snapshot handler. If omitted, genie-web snapshots the element itself: it uses the experimental [HTML-in-Canvas](https://github.com/WICG/html-in-canvas) API when the browser supports it, otherwise the built-in SVG snapshot. Pass a custom function if your project already uses `html-to-image` or `html2canvas`. |
| `open` | No (Vanilla only) | Inferred from CSS | `boolean` | Initial visibility state for `createGenie`. In framework components, control this via the `open` prop. |

`direction` examples:

```js
{ direction: "auto" }    // Automatically inferred from relative geometry
{ direction: "bottom" }  // macOS Dock style: funnel downward
{ direction: "top" }     // Funnel upward
{ direction: "left" }    // Funnel to the left
{ direction: "right" }   // Funnel to the right
```

## Snapshot and HTML-in-Canvas

The warp runs on a WebGL mesh textured with a snapshot of `target`, not the live DOM. That snapshot is taken automatically; you do not need to wire anything up.

1. **HTML-in-Canvas** (preferred when available) — If the browser exposes the experimental [HTML-in-Canvas](https://github.com/WICG/html-in-canvas) API (`layoutsubtree`, `drawElementImage` / `texElementImage2D`), genie-web detects it and uses native element capture. This is typically faster and more faithful than serializing the DOM, so the animation can start sooner and feel smoother.
2. **Built-in SVG snapshot** — Used when HTML-in-Canvas is missing or fails. This is the default path in current stable browsers.
3. **Custom `capture`** — If you pass `config.capture`, that function always wins and the two built-in paths are skipped.

HTML-in-Canvas is still experimental (Chrome origin trial / `chrome://flags/#canvas-draw-element`). Detection is automatic: supporting browsers get the faster path; everyone else keeps the SVG snapshot.

## Vanilla JavaScript

```js
import { createGenie } from "genie-web";

const genie = createGenie({
  target: "#window",
  origin: "#dock-icon",
  duration: 680,
  direction: "auto"
});

await genie.show();
await genie.hide();
genie.set({ duration: 400, origin: "#other-icon", direction: "bottom" });
genie.destroy();
```

| Method | Description |
| --- | --- |
| `show()` | Expand from the anchor point (`origin` → `target`). Returns a Promise. |
| `hide()` | Minimize into the anchor point (`target` → `origin`). Returns a Promise. |
| `set(config)` | Partially update configuration options (including `origin`). Takes effect on the next `show()` or `hide()` call. |
| `destroy()` | Clean up active animations, remove the overlay canvas, and restore target element styles. |

## React

Required props: `open`, `origin`. Optional props: `config`, `className`, `style`.

```tsx
import { Genie } from "genie-web/react";

<Genie
  open={open}
  origin={iconRef}
  config={{ duration: 680, direction: "bottom" }}
>
  <div className="window">…</div>
</Genie>
```

## Vue

Required props: `open`, `origin`. Optional prop: `config`. Additional attributes (such as `class`, `style`) are automatically forwarded to the wrapper `<div>` container.

```vue
<script setup>
import { Genie } from "genie-web/vue";
</script>

<Genie :open="open" :origin="iconEl" :config="{ duration: 680, direction: 'auto' }">
  <div class="window">…</div>
</Genie>
```

## Svelte

**Action directive** — Required parameters: `open`, `origin`. Optional: any configuration field can be passed directly within the same flat options object.

```svelte
<script>
  import { genie } from "genie-web/svelte";
</script>

<div use:genie={{ open, origin: iconEl, duration: 680, direction: "left" }}>
  …
</div>
```

**Component** — Required props: `open`, `origin`. Optional prop: `config`.

```svelte
<script>
  import Genie from "genie-web/svelte/Genie.svelte";
</script>

<Genie {open} origin={iconEl} config={{ duration: 680, direction: "auto" }}>
  …
</Genie>
```
